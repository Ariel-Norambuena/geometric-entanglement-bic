# Two-Stage Bell-BIC Control Protocol

This note is a manuscript-ready draft for the control-protocol section. It is
written as scientific text, but the numerical values currently refer to a
reduced-grid development calculation and must be promoted to production only
after the laboratory-frame and dressed-BIC validation checks.

## Protocol

We prepare the Bell-BIC in two consecutive stages within a single coherent
dynamics. The first stage initializes the one-excitation manifold. Starting
from the vacuum state of the atoms and the waveguide, `|gg,0>`, a resonant
local drive is applied only to atom 1,

```tex
H_{\pi}(t)=\frac{\Omega_{\pi}(t)}{2}
\left(e^{i\varphi_{\pi}}|eg\rangle\langle gg|+
e^{-i\varphi_{\pi}}|gg\rangle\langle eg|\right),
```

with pulse area

```tex
\int_0^{T_{\pi}}\Omega_{\pi}(t)\,dt=\pi .
```

In the development calculation we use a smooth `sin^2` envelope,
`\Omega_{\pi}(t)=2\pi T_{\pi}^{-1}\sin^2(\pi t/T_{\pi})`, and choose
`\varphi_{\pi}=\pi/2` so that the natural `-i` phase of a resonant `pi` pulse
is compensated. During this preparation stage the Floquet couplings are held
at the initial dark-state values, `u_1=0` and `u_2=u_0`, so the prepared
excitation is already aligned with the initial dark atomic direction.

The second stage turns off the local preparation drive and activates the
Floquet passage,

```tex
u_1(t)=u_0\sin\theta(t),\qquad
u_2(t)=u_0\cos\theta(t),
```

where `theta` follows a quintic schedule from `0` to `pi/4`. Thus the target
atomic component evolves as

```tex
|D_a(t)\rangle =
\cos\theta(t)|eg\rangle+\sin\theta(t)|ge\rangle ,
```

which interpolates from the prepared product state to the Bell state
`|\Psi^+\rangle=(|eg\rangle+|ge\rangle)/\sqrt{2}`. To suppress finite-time
nonadiabatic error we add the minimal atomic counterdiabatic term

```tex
H_{\rm CD}(t)=\dot{\theta}(t)\sigma_y ,
```

acting only in the `|eg>, |ge>` subspace.

## Development Result

For the reduced-grid effective-model diagnostic with `Nc=204`,
`xi T_pi=2`, `xi T=20`, `u0=0.9`, and `nu/xi=8`, the local preparation pulse
produces `P_eg=1.000000` at the stage boundary. Without the CD term, the final
state remains close to the original product excitation and reaches only
`C=0.018966`. With the CD correction, the protocol reaches
`C=0.995871`, unconditional Bell fidelity `F_{Psi+}=0.995881`, and
conditional Bell fidelity `F_{Psi+}^{(a)}=0.999990`, while conserving the
total finite-mode norm to better than `3e-13`.

## Manuscript Emphasis

The central point is that the Floquet effective model converts a static BIC
condition into a time-dependent control path. The first stage loads the
desired excitation with a local single-atom drive, while the second stage
geometrically deforms the dark atomic component into a Bell state. The
counterdiabatic term reveals that the low fidelity of the unassisted passage
is a finite-time following problem, not an obstruction to the target state in
the effective model.
